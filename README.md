# TalentQuesst

**Specialist talent search for business-critical non-tech roles — Bengaluru, India**

> _Quesst. Connect. Grow._

TalentQuesst is a specialist talent search firm focused exclusively on business-critical, non-tech roles across Sales & Marketing, Finance & Accounting, Human Resources, Operations, and Legal & Compliance — at every level from senior leadership to junior contributors.

---

## 🌐 Live Site

A Progressive Web App (PWA) built as a single HTML file — zero dependencies, zero build step.
Open `index.html` in any browser or deploy to any static host.

**Deploy instantly to:**
- [Netlify](https://netlify.com) — drag and drop the folder
- [Vercel](https://vercel.com) — import and deploy
- [GitHub Pages](https://pages.github.com) — enable in repo Settings → Pages

## ✨ Features

- **Progressive Web App** — installable on mobile and desktop, offline-capable
- **Single-file architecture** — zero build step, zero npm dependencies
- **Clean corporate design** — Plus Jakarta Sans + Inter typography
- **Fully responsive** — mobile-first, tested at 375px–1440px
- **Smooth scroll-reveal animations** — IntersectionObserver powered
- **Client ticker** — animated scrolling band of client names with brand colours
- **Contact form** — client-side with success state
- **Process strip** — 3-step "How We Work" section
